embedなshell likeな言語を作りたい、という事で、まずは名前を決めてみた。eshlkという名前にする。
[[自作アプリ]]（の予定）。
[[TypeScript]]で作る（予定）。

[[embed用のシェルのような何か]]で考えたもの。

[[Nushell]]みたいなシンタックスの文字列を渡すとJavaScriptにトランスパイルするものを作りたい。
JavaScriptは[[Rhino]]で動く範囲で。
RhinoやNodeからトランスパイルしてevalする感じで実行していく。

コマンドライン的に使えるように、statementが終わっていない状態もちゃんと扱えるものを作りたい。

AndroidとPCで同じスクリプトを使いたい。

[[slog]]みたいな事をしている時に簡単なシェルスクリプトを書いたりしたい。

## 目標とするスクリプト

以下を動かすのを目標とする

```
ui_cd
ls *.md | each {|f| 
    let title = read_lines $f | first | replace '# *' ''
    let date = $f.name | replace '-.*' '' |  replace '_' ''
    {title: $title, date: $date, file: $f}
   }  | ui_select | get file | ui_editor
```
